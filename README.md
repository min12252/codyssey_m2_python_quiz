# 🏆 초성 맞추기 퀴즈 게임

## 1. 프로젝트 개요
다양한 카테고리의 초성을 보고 정답을 입력하여 맞히는 터미널 기반의 퀴즈 게임입니다.
플레이어별 이력 관리와 시간 제한 점수 시스템을 제공합니다.

## 2. 프로젝트 주제 선정 이유
- 터미널 기반 퀴즈게임에 적합한 초성맞추기 게임을 선택하였습니다. 텍스트만으로 터미널에서 실행이 가능하며 쉽게 문제를 생성할 수 있는 주제로 선택하였습니다.

## 4. 기능목록
* 퀴즈 플레이
    * 카테고리 선택: 원하는 주제 선택
    *  초성 퀴즈 풀기: 초성을 보고 정답 입력 (이미 푼 문제는 등장하지 않음)
    * Pass 기능: 모르는 문제는 넘어가고 다음 문제 진행
    * 시간 점수 시스템:
        * 10초 이내 정답: 3점
        * 30초 이내 정답: 2점
        * 30초 초과 정답: 1점
* 문제 관리
    * 카테고리 생성: 새로운 퀴즈 카테고리 추가
    * 문제 등록: 특정 카테고리에 초성과 정답 등록
    * 문제 관리: 등록된 문제 리스트 확인 및 삭제
* 점수 및 플레이어 관리
    * 플레이어 등록: 이름 또는 닉네임으로 사용자 등록
    * 점수 확인: 플레이어별 누적 점수 및 랭킹 확인
